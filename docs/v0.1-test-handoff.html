How to launch

Runs a real RuneLite client with the plugin injected. Use a throwaway/alt F2P account — a fresh profile gets created on first login.

cd /Users/hakonopdal/emdash/worktrees/osrs-mod-choice-rpg/emdash/init-cepqd
JAVA_HOME=/Library/Java/JavaVirtualMachines/jbr-17.0.5-osx-aarch64-b653.14/Contents/Home ./gradlew run

First launch downloads the client. Log in, then find the bronze padlock icon in the RuneLite sidebar (right edge) — that's the Pathlocked panel. Your run profile is stored at ~/.runelite/pathlocked/profile-<hash>.json.
