Pathlocked v0.2 — item tags, skill locks, unlock tree

Branch emdash/v02-core off latest main (post PR #5) · plan per docs/choice-rpg-design.html §8 v0.2 scope: “Item tags + skill unlocks + void-XP tracking; unlock-tree side panel.”

ADecisions (veto by number, otherwise these ship)

1.Starter skills: Attack, Strength, Hitpoints unlocked — plus an instant free skill pick
All other F2P skills start locked. New (and migrated v0.1) profiles get a banked skill draft immediately, so your first act in v0.2 is choosing your gathering/identity skill.
Design doc: “start with 3 combat-ish basics + 1 free pick.” Without the instant pick, a fresh account has zero XP-point sources (combat XP never earns points), which would break the early loop.
2.Draft rotation becomes region → monster → item; every 10th choice is a skill keystone
New DraftCategory.ITEM and DraftCategory.SKILL. Normal drafts rotate the three content categories; every 5th stays the free pick (now sampling all four categories, capped at 6 cards); every 10th is a skill keystone — 3 locked skills, pick 1, reroll as usual. When skills run out, keystones fall back to a free pick.
Design doc: “skills as keystones … the build-defining picks.” Cadence is softlock-guarded: DraftSimulationTest extends to all four categories and must still prove 500 seeds reach 100% completion.
3.Item draft pool: ~17 umbrella tags; starters are Bronze tier, Basic food, Tools
Curate Lane C’s 59 generated tags down to the umbrellas: the 7 metal tiers (bronze→rune, whole tiers — not per-slot), Basic food, Basic runes, Normal logs, Ores, Metal bars, Tools, Ammunition, Ranged weapons, Basic potions. Per-slot subtags (e.g. “Iron helm”) and the 2-item “Seeds” tag are dropped as draft noise. Higher metal tiers only enter the pool once the previous tier is owned (frontier rule, mirrors region adjacency).
A 1-of-3 draft over per-slot tags is 49 near-identical picks; whole tiers make each card a real decision. Starter tags keep the first hour playable with any starting skill choice.
4.Enforcement scope: menu locks + inventory greying now; GE/shop and training-verb blocking deferred to v0.3
Locked-tag items: deprioritize (and optionally hard-block, same two config toggles as monsters) Wield / Wear / Equip / Eat / Drink; grey lock overlay on inventory + bank icons. Locked skills: void XP — earns 0 points, accumulates a per-skill counter shown in the panel, one chat warning per skill per session. No verb blocking yet.
Design doc rates item/menu locking “proven” but verb-blocking only “partial”; keeping v0.2 to the proven surface keeps the branch reviewable. Void XP is the honor-mode mechanism the doc prescribes for skills.

3 · Enforce
